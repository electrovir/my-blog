tags: [dev, git]

-   never merge branches to update them from the base, instead use rebase
-   only use merges when dealing wit PRs and only do squash merging
-   small, chained PRs
-   use `git-vir` to merge chained PRs
-   don't merge PRs into release branches, use `git reset --hard`
-   when to use the VS Code UI (or whatever editor)
