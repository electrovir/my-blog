How to migrate the location of a Plex library, based on what I found online and what I actually had to do for the move to be successful.

<!-- truncate -->

1. backup plex
2. disable the setting to empty trash automatically
3. shutdown plex
4. move (not copy) all files to new location
5. start plex
6. add new location to each library and scan
7. this will reconcile the new file locations with your existing data
8. remove old, empty library locations
9. re-enable emptying trash
