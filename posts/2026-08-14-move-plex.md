title: How to move a Plex library

How to migrate the location of a Plex library, based on what I found online and what I actually had to do for the move to be successful.

<!-- truncate -->

<!-- cspell:words plexmediaserver plexapp -->

1. Backup your Plex data.
    1. `~/Library/Application Support/Plex Media Server/`
    2. `~/Library/Preferences/com.plexapp.plexmediaserver.plist`
2. Disable "Empty trash automatically".
    1. Settings > Library > Empty trash automatically after every scan
    2. Scroll down > Save Changes
3. Shutdown Plex.
4. Move (not copy) all files to new location.
5. Start Plex again.
6. Add the new location to each library.
    1. Settings > Libraries > Edit Library > Add folders
7. Wait for the scan to complete.
    1. If a scan hasn't automatically started, trigger a scan.
8. Remove old, empty library locations from Plex.
    1. Settings > Libraries > Edit Library > Add folders
9. re-enable emptying trash
    1. Settings > Library > Empty trash automatically after every scan
    2. Scroll down > Save Changes
